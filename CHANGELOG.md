# Changelog

## [1.0.0] - 2026-09-12

### Added
- First release. Every note is a tarot card: double gold frame with corner stars on a dark desk, Cinzel titles and headings, Cormorant Garamond body — fonts embedded.
- Callouts are cards — framed, centred, moons in the corners, colour-coded by type — and a folded callout turns face down with a gold lattice card-back.
- Diamond checkboxes, gold oval tags and pills, gold italic highlights, Cinzel table headers and ordinals, black-page code blocks with gold type.
- The explorer as the deck: Cinzel folder labels with stars, italic files, gold-ringed active file, moon phases at the foot. Sidebars and chrome stay night in both schemes.
- Night mode (the black-and-gold deck) and day mode (a parchment card on the same desk).
